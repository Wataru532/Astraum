# Astraum

本物の軌道力学で宇宙機を設計して飛ばす、Windows 向けの宇宙飛行シミュレーターです。

主な遊び方は次のとおりです。

- 太陽系と近くの恒星系を探査する
- 月や火星に地表基地を建設し、そこからロケットを打ち上げる

## 動作環境

| 項目 | 最低要件 | 推奨要件 |
|---|---|---|
| OS | Windows 10（64 ビット） | Windows 11（64 ビット） |
| CPU | x86-64（64 ビット）のデュアルコア | 4 コア以上 |
| メモリ | 4 GB | 8 GB 以上 |
| GPU | OpenGL 3.3 に対応した GPU（内蔵 GPU 可） | Intel Arc 140V（内蔵）程度以上、または同等以上の単体 GPU |
| ビデオメモリ | 2 GB（内蔵 GPU はメインメモリと共有） | 4 GB 以上 |
| ストレージ | 空き容量 300 MB | 空き容量 1 GB 以上（セーブデータとスクリーンショット用） |
| 画面 | 1280×720 | 1920×1080 以上 |
| 入力 | キーボードとマウス（ホイール付き） | 同左 |
| 音声 | なくても動作 | スピーカーまたはヘッドホン |
| ネットワーク | 不要 | 不要 |
| 追加のソフトウェア | なし（最新の GPU ドライバーのみ） | 同左 |

### 補足

- **確認済みの環境**：Windows 11 / Intel Arc 140V（内蔵 GPU）/ 2880×1800 で、最高の地形詳細でも 60 fps で動作しました。上の表の他の構成は、プログラムの仕様から決めた目安で、すべてを実機で試したわけではありません。
- **グラフィック**：OpenGL 3.3 は必須です。古いドライバーでは起動しないことがあるので、GPU のドライバーを最新にしてください。
- **メモリ**：使用量は場面によって変わります。メニュー画面で約 0.8 GB、天体の地表近くで約 1.2 GB です。最大でも 4 GB 以内に収まるよう、キャッシュを自動で解放します。
- **追加のインストールは不要**：必要なライブラリと、地図・音楽などのデータはすべて exe に入っています。.NET や Visual C++ ランタイムなどのインストールも必要ありません。
- **性能の低い PC での設定**：設定画面で次のように変えると軽くなります。
  - 「地形の詳細度」を下げる
  - 「フレームレート上限」を 30 にする
  - 「物理ベースシェーディング」をオフのままにする（既定はオフで、オンにすると高負荷）
- **対象外の環境**：macOS、Linux、ARM 版 Windows、32 ビット版 Windows、Windows 8.1 以前には対応していません。

## 起動方法

1. `Astraum.exe` と `THIRD_PARTY_NOTICES.txt` を同じフォルダに置きます。
2. `Astraum.exe` をダブルクリックします。
   - 署名のない exe なので、初回起動時に Windows SmartScreen の警告が出ることがあります。「詳細情報」を押して「実行」を選んでください。
   - zip でダウンロードした場合は、展開する前に zip のプロパティを開き、「許可する」にチェックを入れると、警告が出にくくなります。

セーブデータと設定は `%APPDATA%\Astraum` に、スクリーンショット（F2）は「ピクチャ\Astraum」に保存されます。F11 で全画面表示に切り替えられます。

## ソースからのビルド（開発者向け）

[w64devkit](https://github.com/skeeto/w64devkit)（GCC）、CMake、Ninja を使います。

```
cmake -B build -G Ninja
cmake --build build
```

実行ファイルは `build/Astraum.exe` にできます。プログラムの構成は [programme_specification.md](programme_specification.md) を参照してください。

## クレジットとライセンス

使用している地図・星のデータの出典と、ライブラリのライセンス文は [THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt) にまとめています。ゲーム内の「設定」→「クレジットとライセンス」からも読めます。
